Studi Kasus: Prediksi Mahasiswa Begadang

Sistem memprediksi apakah seorang mahasiswa akan begadang (tidur melewati tengah malam) berdasarkan empat kondisi sebelum tidur. Dataset yang digunakan merupakan data ilustrasi yang disusun untuk keperluan simulasi algoritme, bukan hasil survei.

Simulasi

1Dataset

Nilai pada tabel dapat diubah langsung. Dataset harus memiliki tepat dua kelas. Baris Target (berwarna) adalah data baru yang akan diklasifikasikan. Parameter m menyatakan jumlah fitur acak yang dipertimbangkan pada setiap node. Seed adalah bilangan awal pengacakan agar hasil dapat direproduksi.

2Konfigurasi Hutan (3 Pohon)

Pada mode Otomatis, bootstrap dan fitur kandidat dipilih secara acak di setiap node. Pada mode Manual, isi ID baris bootstrap (jumlahnya sama dengan banyak data dan boleh berulang) serta fitur kandidat untuk setiap iterasi, berurutan mulai dari akar. Isian Manual bawaan sesuai dengan perhitungan manual pada laporan.

Konsep Dasar

Pilih salah satu kartu untuk menampilkan penjelasan istilah.

Entropy

Ukuran ketidakmurnian data. Bernilai 0 apabila seluruh data berada dalam satu kelas, dan bernilai 1 apabila kedua kelas berjumlah sama.Entropy = -Σ pi·log₂(pi)

Information Gain

Penurunan entropy setelah data dipisah berdasarkan suatu atribut. Semakin besar nilainya, semakin baik atribut tersebut sebagai pemisah.Gain = Entropy(S) - Σ (|Si|/|S|)·Entropy(Si)

Split Info

Ukuran penyebaran data pada cabang-cabang suatu atribut. Nilainya digunakan untuk menormalkan Gain agar atribut dengan banyak nilai tidak diuntungkan.SplitInfo = -Σ (|Si|/|S|)·log₂(|Si|/|S|)

Gain Ratio

Hasil bagi Gain dengan Split Info. Atribut dengan Gain Ratio tertinggi dipilih sebagai node pemisah.GainRatio = Gain / SplitInfo

Bootstrap Sampling

Pengambilan n data secara acak dengan pengembalian. Sebagian data dapat terambil lebih dari sekali dan sebagian lain tidak terambil, sehingga setiap pohon dilatih dengan data yang berbeda.

Out-of-Bag

Data yang tidak terambil pada bootstrap suatu pohon. Data ini dapat digunakan untuk menguji pohon tersebut.

Fitur Kandidat

Pada setiap node hanya m atribut yang dipilih secara acak untuk dibandingkan. Mekanisme ini membuat pohon-pohon dalam hutan saling berbeda.

Mayoritas Vote

Setiap pohon memberikan satu suara prediksi. Kelas dengan suara terbanyak menjadi keputusan akhir hutan.

Alur Algoritma

1Bootstrap sampling: ambil n data secara acak dengan pengembalian.
2Pilih m atribut secara acak pada setiap node.
3Pilih atribut dengan Gain Ratio tertinggi, lalu ulangi hingga data seragam.
4Ulangi proses untuk membentuk pohon kedua dan ketiga.
5Tentukan kelas data baru berdasarkan suara terbanyak.

Uji Pemahaman

Tiga pertanyaan singkat untuk mengukur pemahaman Anda terhadap konsep di atas.

Eksperimen

1. Mengamati pengaruh pengacakan antar pohon

Pengaturan: biarkan ketiga pohon pada mode Otomatis tanpa mengisi seed. Tindakan: jalankan simulasi beberapa kali. Pengamatan: baris bootstrap, fitur kandidat, dan bentuk pohon berubah pada setiap percobaan. Kesimpulan: pengacakan menghasilkan pohon-pohon yang beragam.

2. Mereproduksi hasil menggunakan seed

Pengaturan: isi kolom Seed, misalnya 7. Tindakan: jalankan simulasi dua kali. Pengamatan: hasil kedua percobaan identik. Kesimpulan: seed membuat proses acak dapat direproduksi.

3. Mereproduksi perhitungan manual

Pengaturan: ubah ketiga pohon ke mode Manual dengan isian bawaan. Tindakan: jalankan simulasi. Pengamatan: hasilnya sama dengan laporan, yaitu Ya, Tidak, Tidak, dengan keputusan akhir Tidak.

4. Mengubah data yang diklasifikasikan

Pengaturan: ubah baris Target, misalnya Jadwal Besok menjadi Libur. Tindakan: jalankan ulang simulasi. Pengamatan: prediksi dapat berubah karena jalur yang dilalui pada tiap pohon berbeda.

Pertanyaan Umum

Mengapa hasil setiap pohon dapat berbeda?

Perbedaan berasal dari dua sumber pengacakan, yaitu data bootstrap yang terambil dan atribut kandidat yang dipilih pada setiap node.

Mengapa menggunakan Gain Ratio dan bukan Gain saja?

Gain cenderung memilih atribut yang memiliki banyak nilai. Split Info menormalkan kecenderungan tersebut sehingga pemilihan atribut menjadi lebih seimbang.

Apa perbedaan mode Otomatis dan mode Manual?

Mode Otomatis memilih bootstrap dan atribut kandidat secara acak. Mode Manual memungkinkan pengguna menentukan keduanya, sehingga sesuai untuk mereproduksi perhitungan manual.

Mengapa sebuah daun dapat berisi data dari dua kelas?

Apabila atribut sudah habis dipakai sementara data masih bercampur, kelas daun ditentukan berdasarkan jumlah data terbanyak pada node tersebut.
